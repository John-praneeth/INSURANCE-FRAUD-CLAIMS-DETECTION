Insurance Fraud Claims Detection Engine

ACKNOWLEDGEMENT

In today’s competitive insurance and financial environment, fraud detection and risk screening represent critical challenges faced by insurance carriers. Fraudulent claims range from opportunistic overstatements of property damage to organized collision staging and falsified bodily injury reports. Manual auditing of every submitted claim is cost-prohibitive and slow, while blanket automated approvals expose insurers to severe financial leakage. Identifying claims that are suspicious at an early stage helps organizations allocate investigative resources efficiently and safeguard legitimate policyholders.

The project “Insurance Fraud Claims Detection Engine: Machine Learning Risk Screening Framework” focuses on predicting the likelihood of insurance fraud using supervised machine learning techniques. The system analyzes various multi-dimensional attributes including policyholder demographics, policy terms, incident dynamics, collision severity, vehicle attributes, and monetary claim breakdowns.

The project uses an Automobile Insurance Claims dataset containing 1,000 customer records and 39 predictor attributes. The data is processed and analyzed using Python libraries such as Pandas, NumPy, Scikit-Learn, Imbalanced-Learn, XGBoost, Matplotlib, and Seaborn. Data preprocessing techniques are applied to handle missing values, encode categorical attributes, extract domain-specific ratios, and mitigate class imbalance using SMOTE before training the machine learning model.

An XGBoost Classifier combined with SMOTE and class-weight scaling is used to predict whether a claim is likely fraudulent. In addition to predicting fraud probability, the system categorizes the claim into Low Risk (<30%), Medium Risk (30%–60%), or High Risk (>60%) tiers. This risk-based approach makes the prediction easier to understand and actionable for human claims adjusters.

The developed system is implemented as an interactive Streamlit web application deployed on Streamlit Community Cloud. Users can enter claim details, obtain predicted fraud risk probabilities, visual risk gauges, and tailored investigative recommendations. The application also provides executive dashboards, confusion matrix heatmaps, and comprehensive model performance metrics.

Overall, this project demonstrates the practical application of data analysis, domain feature engineering, supervised classification, imbalanced learning, model explainability, and cloud web application development to solve a real-world enterprise financial risk problem.

4. PROJECT: INSURANCE FRAUD CLAIMS DETECTION ENGINE

4.1 Objective

The main objective is to identify potentially fraudulent automobile insurance claims well in advance, enabling claims adjusters to prioritize investigations, reduce financial leakage, and expedite legitimate payouts.

4.2 Problem Statement

Given 39 heterogeneous customer, policy, incident, and vehicle attributes, can we train a supervised classifier that accurately predicts the probability of fraud (fraud_reported = 1), while controlling false alarms and presenting actionable insights via an intuitive web dashboard?

4.3 Dataset Description

The dataset contains 1,000 claim records with 39 predictor attributes and 1 binary target (fraud_reported: 753 Legitimate vs 247 Fraudulent claims). Missing values encoded as '?' in collision_type, property_damage, and police_report_available were transformed into explicit 'MISSING' tokens.

4.4 Preprocessing & Architecture

def create_preprocessor_pipeline(num_cols, cat_cols):
    num_pipeline = Pipeline([
        ("imputer", SimpleImputer(strategy="median")),
        ("scaler", StandardScaler())
    ])
    cat_pipeline = Pipeline([
        ("imputer", SimpleImputer(strategy="constant", fill_value="MISSING")),
        ("onehot", OneHotEncoder(handle_unknown="ignore", sparse_output=False))
    ])
    return ColumnTransformer(transformers=[
        ("num", num_pipeline, num_cols),
        ("cat", cat_pipeline, cat_cols)
    ], remainder="drop")
